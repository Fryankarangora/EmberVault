# EmberVault

Turns personal financial data into a secure, portable, and easily exportable PDF file for individuals and small businesses.

The key benefits of using EmberVault include:

- Turns personal financial data into
- a secure, portable, and easily
- exportable PDF file for individuals

- python

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/EmberVault.git`
2. `cd EmberVault`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
